# Aktiv opgave — Nembyggestyring UI/UX v2 (planlægning, ingen designændringer endnu)

Besigtigelses- og notifikationsarbejdet (multi-tids besigtigelse,
in-app notifikationer til begge roller, entreprenør-navigation og
badge, middleware-rettelse for delte ruter) er implementeret, deployet
og browsertestet af Oliver — afsluttet, ingen opfølgning påkrævet. Se
git-historik og docs/PROJECT_STATE.md for detaljer.

Næste fase er "Nembyggestyring UI/UX v2". Der er endnu ikke lavet
designændringer, produktkode, SQL eller commits i denne fase — kun
forberedelse af faste arbejdsregler (se CLAUDE.md, "Arbejdsproces og
rapportering") og docs-struktur. Det konkrete scope for selve UI/UX v2
afventer Olivers instruktion.

Permanente UX/UI-principper (gælder allerede nu og fremover, ikke kun
for v2) står i docs/DECISIONS.md, "UX/UI-principper".

# Tidligere afsluttede faser

Se docs/PROJECT_STATE.md for fuld historik (chat, navigation,
sikkerhedsrettelser, besigtigelse, notifikationer, projektgrundlag).
Ingen kræver yderligere opfølgning, medmindre andet fremgår af
PROJECT_STATE.md.

Ældre, ikke-eksplicit-bekræftede browsertest-punkter (V2-dokumentformat/
fjernelse af Projektopsummering, samt de tidligste projekt-/
kontraktroute-sikringer) er ikke gentaget her for at undgå dokumentbloat
— den fulde, tidligere testplan findes i git-historikken for denne fil
(`git log -p docs/ACTIVE_TASK.md`), hvis den skal følges op på.
